# Raw data zone

Raw data is immutable and excluded from Git; use original filenames. Source folders use original/, extracted/, metadata/, checksums/, manifest.csv and README.md. Owner: Data/GIS/AI (Area D). Inputs: downloaded source files or permitted API returns. Outputs: unchanged sources and evidence-based manifests. Do not store credentials or edited originals.
