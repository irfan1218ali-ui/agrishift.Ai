# Data workspace

Owner: Data/GIS/AI (Area D). Inputs: the six MVP sources and approved farmer-provided inputs. Outputs: cataloged raw/interim/processed/model-ready assets and evidence-linked manifests. Do not store credentials, unrelated providers, or identifiable farmer data in public samples.

Four zones are `raw/`, `interim/`, `processed/`, and `model-ready/`. Large scientific data are ignored by Git; keep instructions, catalogs, manifest templates, schemas and small sanitized samples. The active catalog contains only SMAP, GPM IMERG, Landsat, terrain, NASA POWER and Meteomatics.

Must not store: credentials, raw scientific source files outside designated raw folders, or private farmer data in public samples.
