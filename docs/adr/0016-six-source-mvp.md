# ADR 0016: Six-source MVP scope

Status: Accepted. Date: 2026-11-15.

Lock MVP integrations to NASA SMAP, NASA GPM IMERG, USGS Landsat 8/9 C2 L2, NASA SRTM/NASADEM, NASA POWER API and Meteomatics Weather API. This balances moisture, rain, field imagery, terrain, historical climate and forecast inputs while keeping four-owner integration scope manageable. Excluded candidates are future-only and have no active runtime config or adapters.
