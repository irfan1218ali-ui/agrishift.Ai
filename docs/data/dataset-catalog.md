# Six-source dataset catalog policy

`data/catalog/datasets.csv` is the catalog authority and contains only SMAP, GPM IMERG, Landsat C2 L2, SRTM/NASADEM, NASA POWER and Meteomatics. `variables.csv` maps source variables to normalized concepts/units; blank values mean not established, not zero. `api-endpoints.csv` lists only NASA POWER and Meteomatics. `data-status.csv` tracks lifecycle using the documented status vocabulary; no dataset is marked validated until its actual contents and metadata are inspected.

Use stable dataset IDs independent of filenames. Record provider/product/version, purpose, variables, native spatial/temporal resolution, coverage, location/date range, access, format/CRS when known, local path, status, limitations, license reference and notes. Unknown metadata remains blank with a note.

Four storage zones are immutable raw, reproducible interim, validated processed, and versioned model-ready assets. Keep scientific data and sensitive API payloads out of Git; preserve documentation, catalogs, manifests and schemas. Each asset manifest links original filename/path, checksum, size, source, UTC time, CRS/transform/resolution, NoData, scale/offset, quality state, license and validation notes. Derived assets record code/config version and upstream checksums. Dataset versions are immutable; changes create new versions. Review attribution and redistribution rights before publication.
