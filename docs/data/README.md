# Data documentation

- `source-inventory.md`: observed source assets, metadata, measured summaries, and missing files.
- Source-specific files: SMAP, GPM, Landsat, terrain, NASA POWER, and Meteomatics.
- `data-management.md`: immutable raw/interim/processed/model-ready handling.

Credentials and unreviewed private farmer data must not be stored here.

## Documentation ownership

- Owner: Data engineering
- Inputs: Validated source metadata, provider documentation, and measured local assets.
- Outputs: Source inventory, data handling policy, and source-specific limitations.
- Must not store: Credentials, unreviewed farmer records, or fabricated measurements.
